
# Banking Project — Frontend

React and TypeScript frontend for the Banking Project application.

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
- React Router
- TanStack Query
- shadcn/ui
- Axios
- Recharts
- Lucide React

## Requirements

- Node.js
- npm

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Production Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```

## Architecture

The application uses a feature-based structure:

- `app/` — application providers and routing
- `components/` — shared UI and layout components
- `features/` — business features
- `lib/` — shared utilities and API client
- `types/` — TypeScript types
